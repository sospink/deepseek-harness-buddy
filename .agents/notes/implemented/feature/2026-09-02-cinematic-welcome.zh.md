# 影片化空白会话欢迎页

[English](2026-09-02-cinematic-welcome.md) | 中文

浏览器中的首个空白 Buddy 会话现在会打开单视口视频落地页，其中包含响应式导航、信任标识、本地化首屏文案、动态指标页脚与移动端菜单。页面保留现有 Conversation composer 的挂载状态以维持连续性，但在欢迎层可见时会收起其渲染控件。

当检测到落地页标记时，AppFrame 会临时将侧栏与详情栏轨道宽度解析为零。进入该状态时会关闭普通的列宽过渡，并立即清除常驻 Hero 容器为悬浮侧栏保留的水平位移；因此从展开侧栏的会话页重新打开欢迎页时，首个绘制帧就会铺满全宽，不再短暂保留一块侧栏宽度的黑色空隙，也不会从右侧滑入。它们已挂载的子树也会从交互与无障碍树中隐藏。选择“开始使用”后，界面会记录带版本的浏览器确认、关闭欢迎层、恢复正常三列应用框架，并将焦点移到常驻 composer。后续刷新会直接初始化工作区，不会闪现落地页。共享的 `UiConversation` 欢迎状态允许用户点击展开侧栏的品牌区来清除确认记录、打开空白 Session 并再次显示落地页，同时保留已有 Session。活跃对话与全画布 Conversation 视图不会进入欢迎状态。

展示面从 Web public 目录提供已给定的 H.264 背景视频，因此欢迎画面不依赖客户网络。打包的 JPEG 封面同时作为视频加载帧与其下方的背景层，因此解码失败或自动播放延迟时仍会保留同一构图，而不是暴露黑色画布。展示字体在可用时使用已给定的 CDN 字体，并使用本地打包的 Geist Pixel Circle 作为回退。减少动效路径会跳过揭示动画与数字动画。
