# @sospink/dsh-buddy-client-ui-development-management

[English](README.md) | 中文

## 概述

本浏览器插件在侧边栏增加“开发管理”，并挂载全窗口深色亚克力工作区。高密度需求表展示优先级、状态、创建者、指派人、评审人、阶段和更新时间，不把研发流程改成普通卡片后台。角色选择用于限定可见工作台，同时 Host 会独立校验每一次写操作。

产品经理可创建、评审、指派需求，查看附件、详情和历史。被指派的工程师可接收任务，上传文件或浏览器选择的完整目录，并填写必填成果说明后提交验收。产品经理在专用弹窗中查看提交内容，可验收通过或填写必填原因后退回；详情页保留最近一次提交与审核结果。验收通过后，工程师才可配置允许访问的本地仓库、申请并执行交付检查，并查看文件差异、疑似冲突、命令日志、Agent 结论和生成的 Merge Request 文本。最终人工确认和已合并证据控件只出现在产品经理视图。

## 已知限制

- 浏览器目录上传依赖 `webkitdirectory`；Chromium 系交付浏览器支持该能力，但它不是标准完备的目录选择 API。
- 较长的检查套件仍是一次有人值守的操作；当前显示忙碌进度，但暂不在执行过程中逐条流式展示命令日志。
- 远程 Git 凭据和提供方配置属于部署配置，因此不会出现在浏览器 UI。
