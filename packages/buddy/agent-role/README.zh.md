# @sospink/dsh-buddy-agent-role

[English](README.md) | 中文

## 概述

本 Host 包允许用户在 Buddy 会话开始前选择专业工作身份。内置目录包含通用 Agent、业务需求分析师、产品方案设计师、原型设计师、软件架构师、AI 应用工程师、区块链工程师和代码审查专家。

身份与 Agent Preset 相互独立：Preset 决定工具、权限和插件组合；身份为模型上下文增加专业工作方法。所选身份会记录为 `agent-role/selected`，投影到会话摘要，并在每次模型请求时从日志重新折叠，因此刷新、恢复和派生会话都会保留身份。

## 模型体验

通用 Agent 不增加额外文本。每个专业身份增加一段稳定的运行时上下文，说明职责、决策标准和防止臆造的边界。身份只能在 `turn/start` 前选择，从而保持同一会话行为稳定，并保持请求前缀适合 KV 缓存。

Complete Persona Preset 按设计可以屏蔽运行时上下文。此时 Complete Persona 仍具有最高优先级，但身份事实仍会持久记录并显示。

## 已知限制

- 当前身份目录由产品代码固定，管理员还不能在设置中新增自定义身份。
- 首轮开始后身份固定；如需更换身份，请新建会话。
